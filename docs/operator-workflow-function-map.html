Notion-Projektion

Notion ist operative Projektion, aber niemals technische Statusautorität.

1. Core Event

Projekt, Run, Step, Task, Artefakt, Gate, Approval, Release oder Fehler wird append-only gespeichert.

2. Notion Adapter

Heute lokal simuliert. Später Live-Modus mit expliziter Connection und idempotenter Delivery.

3. Record Map

Customer, Project, Run, Step, Task, Assignment, Artifact, Gate, Review, Approval, Blocker, Defect, Escalation, Performance und Integration Status.

4. Notion

Status, Titel, Revision und Relationen. Keine direkte Mutation des Core-Status.

Heute: Notion-Simulator und später manueller Import Pack. Nicht implementiert: echter externer Notion-Write. Ein zukünftiger Live-Sync benötigt Preview, Bestätigung, Adapter-Response und Core-Readback.

Was der Admin am Ende tatsächlich tun kann

Briefing rein

Markdown hochladen oder einfügen, extrahierte Felder korrigieren, Intake bestätigen.

Workflow ausführen

Step starten, Fortschritt sehen, Machine Gate und Output prüfen.

Editieren und freigeben

Draft bearbeiten, neue Revision speichern, vergleichen, validieren, freigeben oder wiederholen.
